# Credits

All textures in this pack are extracted, unmodified, from the
[Mineclonia](https://codeberg.org/mineclonia/mineclonia) project — an
unofficial Minecraft-like game for Luanti (formerly Minetest).

This repository does not create or modify any artwork. It only automates
repackaging Mineclonia's `mods/**/*.png` files into a standalone texture
pack whenever upstream publishes a new release with texture changes.

- Upstream project: https://codeberg.org/mineclonia/mineclonia
- Upstream contributors: see `CREDITS.md` in the Mineclonia repository
